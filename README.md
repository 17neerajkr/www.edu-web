# 📚 Student Dashboard – EDU-WEB

An interactive, responsive **Student & Teacher Dashboard** built using **HTML, CSS, and Bootstrap**, deployed live on **Netlify** 🌐.  
This project allows seamless interaction between students and teachers, sharing course material, progress, tasks, and performance analysis all in one place.

> 🔗 **Live Link**: [Visit on Netlify](https://WWW.EDU-WEB.netlify.app)  
> 🎬 Scroll down for screenshots, features, and usage.

---

## 🧾 Project Description

The **Student Dashboard** is a mini Ed-Tech web application designed to:

- 👩‍🏫 Support **student and teacher login**
- 🔄 Enable **real-time data sharing** between teachers & students
- 📊 Track **progress, assignments, schedules, and course content**
- 📋 Provide a **central panel** for all academic-related tasks and analytics

Built as a front-end static app and styled using modern UI components, the goal is to make information accessible, structured, and student-centric.

---

## 🚀 Features

✅ Student & Teacher Login Panel  
✅ Dashboard with Assignment, Course & Task Tracking  
✅ Responsive Sidebar Navigation  
✅ Live Analytics: Progress % and Task Status  
✅ Daily Schedules with Timings  
✅ Noticeboard with Dynamic Updates  
✅ Footer with Contact Links & Social Media  
✅ Stylish Cards for Course Performance  
✅ Fully Responsive for Desktop & Mobile
